# Code of conduct

Cantina is a personal hobby project with one maintainer. If you interact here — issues,
pull requests, discussions — the expectation is the ordinary one: be respectful, argue
about the work rather than the person, and accept that the maintainer decides what the
project does.

Harassment, personal attacks, and bad-faith participation are not welcome, and the
maintainer will close, lock, or block as needed to keep the space workable.

Report a problem with someone's conduct the same way security problems are reported —
see [`SECURITY.md`](SECURITY.md) — rather than escalating in a public thread.
