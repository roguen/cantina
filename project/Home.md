# Cantina project home

Cantina is a LAN setlist remote for stock YARG. The iPad is a thin installed web app;
Barkeep runs beside YARG on the theater PC and owns all authoritative application
state.

## Current state

M0 foundations are in progress. No UDP, input-injection, deterministic-selection, or
Windows 10 deployment claim is closed until its linked issue contains target-PC
evidence.
